# Десять разных дорог в фэнтези

Десять самостоятельных кампаний для **3–8 игроков плюс ведущий**. В каждой восемь
разработанных сессий и восемь готовых героев 3-го уровня. Все рассчитаны на совместную
игру подростков и взрослых; возрастные рекомендации относятся к темам, а не к ролям.

Откройте [локальный каталог](index.html). Книги ведущего содержат спойлеры. Игрокам
передавайте только самостоятельный `players.html` и уже открытые раздатки по одной.

## Подготовка и импорт

1. Выберите книгу ведущего, прочитайте начало и договоритесь о темах и паузах.
2. Импортируйте `package.json` в личный черновик Мастерской: это состав на 4 игроков.
   Для другого состава используйте `variants/3-players.json` … `variants/8-players.json`.
3. Проверьте предпросмотр и подтвердите запуск штатным действием ведущего.
4. Используйте обычные приглашения проекта. Файлы не назначают реальных пользователей.

Варианты используют первые N героев; первые три составляют самостоятельное ядро.
Другой набор героев можно согласовать и изменить в черновике с повторной проверкой.
Будущие сцены, решения и финалы — подготовка ведущего, а не уже сыгранная история.
Тактические сетки — функциональные схемы; оригинальные растровые иллюстрации не создавались.
Встречи необязательны; история предусматривает переговоры и выход при неудаче.

## Воспроизведение

```sh
node --conditions=@ltw/source scripts/fantasy-campaigns/build.ts
node --conditions=@ltw/source scripts/fantasy-campaigns/render.ts
pnpm exec vitest run --project unit scripts/fantasy-campaigns
```

`source/` — авторский материал. HTML, `package.json`, `variants/` и `maps/` — результаты
сборки. Сборка и рендер принимают slug для точечного запуска. Полный рендер обновляет каталог.
`verification.json` содержит оценки изолированного компилятора и хеши пакетов.

Каждой кампании назначен отдельный агент с конфигурацией `gpt-6-astra`, effort `max`.
Это не запись о провайдерском запуске внутри приложения. Живой плейтест с людьми не проводился;
длительность и баланс требуют проверки за столом. Выполненные технические проверки и
ограничения фиксируются в `../../reports/FANTASY_TEN_2026-11-08.md`.
