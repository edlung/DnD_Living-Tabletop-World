# Широкий Порог: границы контекста

Авторизованный объём: `work-orders/FANTASY_TEN_2026-11-08.md` и
`scripts/fantasy-campaigns/CONTENT_CONTRACT.md`. Эта папка принадлежит одной кампании;
соседние кампании, общие сборщики и продуктовый код здесь не редактируются.

Читайте `README.md`, затем нужные ключи в `source/`. Четыре файла встреч содержат по две
встречи. Все JSON — авторский источник, не журнал сыгранных событий. Будущие ситуации
становятся фактами только после действий за столом и решения DM.

Папка целиком предназначена ведущему. `truth`, секреты и знания NPC, условия выдачи
раздаток, улики до осмотра, последствия и заметки встреч не являются стартовым знанием
игроков. Игровая раздатка раскрывается по её `unlock`; нельзя раздать всё при старте.

Сохраняйте конструктивный сюжет: разные потребности, независимые пути, личные границы,
обычные недостатки жителей. Не добавляйте тайного чудовища-злодея, древний механизм,
обязательный штурм или голосование о праве кого-либо на дом. Финальный формат выбирают
игроки; частное убежище и отложенное открытие — полноценные условные исходы.

Все восемь героев равноправны; первые трое достаточны для всей истории. Никакая улика,
проверка или развязка не требует дополнительного места, класса либо заклинания.
Поддерживайте каждый состав 3–8 плюс отдельный ведущий, смешанный стол 12+ и право паса.

Генерируемые `package.json`, `variants/`, `index.html` и книги собирает интеграционный
процесс коллекции. Их не используют как авторский источник и не редактируют вручную.
Изображения, платные задания, активация, сеть и новые зависимости к этой работе не относятся.

Проверка источника:

```sh
node --input-type=module -e "import('./scripts/fantasy-campaigns/source.ts').then(async m => { const s=await m.loadSource('dungeon-sanctuary'); const e=await import('./scripts/fantasy-campaigns/editorial.ts'); e.verifySource(s); console.log('source OK'); })"
```
