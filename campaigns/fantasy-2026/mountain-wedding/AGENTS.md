Читайте `README.md`, затем нужные ключи в `source/` по полю. Четыре файла сессий содержат по два

игроков); меняйте их только вместе с повторным прогоном. Текст написан Sonnet 5.5 через API проекта
по скелету Opus 5.5; повторный платный вызов — только по решению владельца
(`scripts/campaign-shared/AGENTS.md`). Картинки — генерация изображений OpenAI; оригиналы и промпты в
`~/Documents/living-tabletop-world-art/mountain-wedding-2026-11-14/`. Пакеты и HTML не правьте
вручную: редактируется `source/`.
