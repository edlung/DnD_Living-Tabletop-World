# Десять миров для общей истории

Десять самостоятельных русских кампаний для **3–7 игроков плюс ведущий**. Восемь
специально задуманы для подростков и взрослых вместе; ещё две используют более напряжённые
или личные темы для старших подростков. Каждая состоит из восьми вечеров и семи готовых героев.

**Статус:** все десять кампаний написаны и собраны. 50 нативных вариантов имеют статус
READY; 80 проверок прошли. HTML-книги проверены на четырёх ширинах экрана.

## Начать игру

1. Откройте книгу ведущего, первый вечер и правила своей группы. Ведущий не входит в число игроков.
2. Передайте участникам отдельный `players.html`: он содержит собственное оформление и работает
   без остальной папки. Раздатки из `handouts/` выдавайте по одной, когда выполнено условие в книге.
3. Для игры в приложении импортируйте `package.json` в личный черновик Мастерской: это **4 игрока**.
   Иной состав: `variants/3-players.json` … `variants/7-players.json`.
4. Проверьте состав и открывающую сцену в предпросмотре. Запуск подтверждает ведущий обычным
   действием; управление получают через штатные приглашения. При отсутствии изображений
   используйте предусмотренный проектом текстовый режим.

Варианты берут первых N героев; первые три составляют полноценное ядро. Другое сочетание
можно изменить в черновике и повторно проверить. Нефэнтезийные образы используют существующие
правила уровня 3: новая техника или профессия не добавляет автоматических возможностей.
Проверки из книги и сюжетные последствия разрешает ведущий. Подготовленная сцена не означает,
что персонажи уже совершили описанные действия или выбрали финал.

Вся папка с исходниками и пакетами предназначена ведущему и содержит секреты. Отдельный файл
игроков удобен для передачи; весь каталог не является защищённым публичным хранилищем.

## Файлы и повторная сборка

- `source/` — авторский мир, персонажи, улики, раздатки, восемь вечеров и необязательные встречи.
- `index.html`, `session-1.html` … `session-8.html` — книга ведущего.
- `players.html` — отдельная книга игроков с образами героев и основными числами листов.
- `handouts/` — самостоятельные файлы для передачи после открытия; `maps/` — функциональные SVG.
- `package.json`, `variants/`, `verification.json` — нативные пакеты и их технические результаты/хеши.

Из корня проекта:

```sh
node --conditions=@ltw/source scripts/mixed-campaigns/build.ts
node --conditions=@ltw/source scripts/mixed-campaigns/render.ts
node --conditions=@ltw/source scripts/mixed-campaigns/verify-artifacts.ts
pnpm exec vitest run --project unit scripts/mixed-campaigns
pnpm exec tsc -p scripts/mixed-campaigns/tsconfig.json
node --conditions=@ltw/source scripts/mixed-campaigns/audit.ts
```

`build.ts` и `render.ts` принимают один или несколько slug для точечной сборки. Только полный
рендер обновляет общий каталог. Рендер также удаляет устаревшие **сгенерированные** раздатки
и карты при изменении их ключей. Правьте исходники, не производные HTML/SVG/пакеты.
`audit.ts` использует установленный `ui-layout-audit`; альтернативный путь к `audit.mjs`
можно передать первым аргументом.

Каждая кампания создана отдельным агентом с конфигурацией `gpt-6-astra`, effort `max`.
Это авторские материалы, не фиктивные задания AI-провайдера приложения. Растровые иллюстрации
не создавались. Баланс и длительность ещё не подтверждены живой группой. Общая техническая
проверка и ограничения зафиксированы в [итоговом отчёте](../../reports/MIXED_TEN_CAMPAIGNS_2026-11-08.md).
