# Бюро украденного дождя

Область: только этот каталог. Контракт: `../../../scripts/mixed-campaigns/CONTENT_CONTRACT.md`.
Начинайте с README и нужного ключа в `source/`; не читайте другие кампании.

- Оригинальный камерный детектив 12+ для подростков и взрослых, 3–7 игроков плюс ведущий.
- Центральный факт ведущего: кражи не было; это постановка заказчика. Не заменять сюжет аварийным городским механизмом, настоящим похищением артефакта или общественной реформой.
- Сохранять истинное кафе-алиби, отдельное время подготовки, ограниченную магию парной бумаги и три независимых пути проверки.
- Алёна — давно признанный независимый эксперт; её конфликт о проверяемости и допустимом раскрытии метода. Не возвращать линию забытого соавторства, утраченного имени или финальной награды за восстановление славы.
- `truth`, секреты/знание NPC, `statement`, `unlock` и подготовленные сцены принадлежат ведущему. Публичный текст и внешность не раскрывают разгадку. Будущие опыты не являются уже выполненными фактами.
- Первые три героя полностью жизнеспособны; остальные места необязательны. Признание, бой, прощение и публичное выступление не обязательны.
- Сохранять конкретные выборы, их цены, резервные пути, доступ без броска, ротацию слова и равное влияние возрастов.
- JSON имеет точные поля контракта; два вечера на файл, меньше 500 строк на файл, строковые поля меньше 1800 символов, `play` максимум 1750 символов и не короче 100 русских слов (`docs/CAMPAIGN_TEXT_STANDARD.md`).
- Не редактировать сгенерированные пакеты, варианты и HTML вручную. Не менять общий tooling. Проверять `source.ts` / `editorial.ts` командой из README и честно отделять её от нативной сборки и человеческого плейтеста.
