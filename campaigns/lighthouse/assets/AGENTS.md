# Campaign art

Original artwork generated for this owner request with the built-in imagegen tool. Read the
manifest/prompts, then view only the relevant raster when needed. Preserve original generated
files and their provenance. No production provider, API key, fake job or paid-project ledger entry.
Every deliverable must be copied into this directory before being referenced by the campaign.
Player-safe means the pixels disclose no hidden solution or identity; reveal timing still matters.
Presentation art never supplies collision geometry or grants canonical knowledge by itself.
