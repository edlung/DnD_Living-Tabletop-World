# «Завещание Пепла»

Авторская область — только этот каталог; редактируется `source/`, пакеты и HTML собирают инструменты
`scripts/campaign-collection/`. Сюжет, ключи и числа — по `campaigns/distinctness/ash-testament-skeleton.md`.
Читайте `README.md`, затем нужные JSON по ключу; не загружайте целиком пакеты и HTML.

Строго 21+: все названные люди старше 21. Конвой сдавшегося свидетеля по мачтам: давление — флаги колонны на
`station-map`, раскрытие — раздатка `efim-testament` (завет Ефима, вечер 6, его читает стол), судьба Ефима
решается в конце вечера 7 по разрыву (к колонне Румы или у Двух вех) — на настиле его нет; финал — бой
`long-planks-ambush` за ящик Чаши (правило на `plank-card` и в тактике встречи), три исхода «Ящик у стола»,
«Копии у стола», «Пепел» без таблицы и эпилогов. Подпись героя в листе № 14 и под заветом — только с
согласия его игрока; герою вину не назначать. Ни герои, ни Ефим не гибнут.

`truth`, тайны и знания NPC, условия выдачи раздаток и заметки ведущего — только ведущему. Карты боёв
зависят от ключей встреч: ключи и клетки менять только вместе. Числа противников и блок босса меняются
только вместе с прогоном движка. Числа ящика Чаши (целость, урон, Заслон, 3 клетки) меняются
только вместе с моделью `reports/evidence/ash-testament-rework-2026-11-16/finale-sim/`.
