# «Бархатный Реестр»

Авторский источник кампании 21+, переписанный 16 ноября 2026 по
`campaigns/distinctness/velvet-ledger-brief.md` и скелету `velvet-ledger-skeleton.md`
(tier A, `engine: "market-duel"`, ритм «торговые дни»). Этот каталог принадлежит только данной
кампании; другие кампании и общие сборщики отсюда не менять. Начинать с README и нужных ключей
`source/`, не читать собранный пакет целиком.

- Следовать `scripts/campaign-collection/CONTENT_CONTRACT.md` с поправками серии: поле
  `world.engine`, `items.json`, встречи с `foes`/`boss`/`layout`/`mandatory`.
- Русская проза; все именованные люди 21+. Скелет — источник ключей, чисел и сюжета: новые события,
  NPC и числа доски не придумывать. Числа доски, сделок и последнего колокола меняются только
  вместе со скелетом и пересчётом трёх столов.
- Отличительная основа: биржевая дуэль за чужой долг, утренний и вечерний колокол, одна доска
  (Долг, Касса, Курс Дома), Книга называет хозяина, финал — двенадцать ударов последнего колокола.
  Не превращать игру в расследование ради суда, ограбление или охоту на человека.
- Запрещено: суд или слушание в финале, тайный предатель среди союзников, отдельная сессия
  планирования, круг эпилогов, таблица исходов, читаемая в конце, «каждый называет…». Утренний
  колокол — ответ стола ценой, а не круг признаний.
- Три пути к Книге в вечере 5 независимы, ни один не за обязательным броском; у каждой улики есть
  `fallback`. Седьмой и восьмой герои ни для чего не обязательны.
- `appearance`, описания мест и предметов, поля героев безопасны для игроков; `truth`, тайны и
  `knows` NPC, Ключ до вечера 5, условия выдачи раздаток и сцены — только ведущему. NPC знает
  только свой `knows`; будущие ходы Дома — условные события, не исполненные факты.
- Биржа, Книга, ярлыки и паи — вымышленная магия Вельтеня: без реальных биржевых схем, подделки
  документов, обхода охраны и вскрытия замков. Драки короткие, упавшие оглушены.
- Механика — поддерживаемые классы третьего уровня и обычные проверки. Числа противников даны для
  четырёх игроков; меняйте их только вместе с прогоном движка.
- Исходники держать короче 700 строк на файл, по две сессии в файле. Пакеты и HTML собираются
  `build.ts`/`render.ts`, вручную не правятся. Растровых иллюстраций пока нет; живой плейтест не
  подменять машинной проверкой.
