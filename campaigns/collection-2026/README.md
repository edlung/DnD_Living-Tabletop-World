# Десять миров для большого стола

Десять самостоятельных кампаний на русском языке. Каждая рассчитана на восемь сессий,
пять–восемь или шесть–восемь игроков **плюс один ведущий**. В каждой восемь готовых героев
3-го уровня, самостоятельный сюжет, улики, раздатки, несколько исходов и необязательные бои.

Откройте **[каталог](index.html)** и выберите книгу. Страницы работают локально, без сервера.
Книги ведущего содержат спойлеры. Передавайте игрокам только отдельный `players.html`;
конкретные материалы из `handouts/` выдавайте по условиям сценария. Наличие отдельной
страницы не превращает весь каталог в защищённое публичное хранилище.

Конкретные темы и границы указаны в книге каждой кампании.

## Импорт в проект

1. Войдите в мастерскую и откройте свой черновик.
2. Импортируйте `package.json` выбранной кампании — состав по умолчанию **6 игроков**.
   Для другого состава выберите соответствующий `variants/N-players.json`.
3. Проверьте сценарий, героев и встречи в предпросмотре. Активацию подтверждает ведущий.
4. Игроки получают управление через обычные приглашения проекта, а не из файлов кампании.

Варианты используют первые N героев в порядке карточек. Основная история не требует
дополнительных мест. Для произвольной замены героев отредактируйте черновик и повторите проверку.

Необычные жанры используют поддерживаемые правила проекта: профессии и оборудование получают
жанровое описание, но не добавляют автоматическое управление кораблями, взлом или новые классы.
Сюжетные часы, массовые работы, договоры и последствия выбора ведёт DM. Нативные пакеты
содержат подготовленные ситуации, а не уже состоявшиеся победы или решения.

## Файлы и воспроизведение

- `source/` каждой кампании — исходный авторский материал.
- `index.html`, `session-N.html` — книга ведущего и восемь вечеров.
- `players.html` — завязка и восемь карточек без тайн ведущего.
- `handouts/` — отдельные раздатки, `maps/` — SVG-сетки из геометрии встреч.
- `package.json`, `variants/` — пакеты импорта, `verification.json` — результаты и SHA-256.
- `../../scripts/campaign-collection/` — сборка, рендер и проверки.

Из корня проекта:

```sh
node --conditions=@ltw/source scripts/campaign-collection/build.ts
node --conditions=@ltw/source scripts/campaign-collection/render.ts
pnpm exec vitest run --project unit scripts/campaign-collection
```

Обе команды принимают один или несколько slug для точечного пересоздания. Общий каталог
пересобирается при рендере всех десяти кампаний. Встроенные исходники не требуют внешней сети.

Каждая кампания поручена отдельному агенту с запрошенными `gpt-6-astra` и `max`.
Это авторская работа в текущей сессии, не фиктивная запись об AI-запуске в приложении.
Растровые иллюстрации не создавались. Живое прохождение, длительность и баланс пока не
подтверждены группой; техническую проверку и ограничения фиксирует итоговый отчёт
`../../reports/TEN_CAMPAIGNS_2026-11-08.md`.
