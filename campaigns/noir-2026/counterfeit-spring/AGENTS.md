# Поддельная весна

Локальный scope: только этот каталог. Контракт: `scripts/noir-campaigns/CONTENT_CONTRACT.md`.
Читайте README и нужный ключ исходного JSON; не загружайте целиком сгенерированные книги.

- Десять JSON в `source/` — авторский источник; пакеты, варианты и книги пересобираются родительским инструментом.
- `world.truth`, `case.json`, секреты NPC, указания ведущему и условия выдачи раздаток приватны для ведущего.
- Все персонажи старше 21 года. Живопись нынешнего сезона; художники живы. Нет убийства, похищенного архива или экспертного приговора.
- Виновник фиксирован: дилер Аркадий Сухов. Знание Бирка и Крупиной доказывается отдельно; деньги не распределяются автоматически.
- В NPC `secret` и `knows` нельзя помещать неизвестный персонажу факт даже через отрицание «не знает, что». Такие границы пишутся в `boundary`, `reveal` и материалах ведущего.
- Три маршрута независимы. Чужие помещения, почта и картины требуют добровольного доступа; отказ не обосновывает обязательный бой.
- Будущий показ, признание, оплата и возврат не становятся фактами до разыгранного решения. Раннюю отмену продажи нельзя отменять ради финала.
- Сохраняйте шесть размеров 3–8, ядро из первых трёх героев, 24 развёрнутые сцены, варианты без броска и конечные ограничения согласия.
- Не изменяйте общие файлы, другие кампании, приложение или внешние сервисы. Не запускайте CLI аудита, пишущий общий отчёт, из авторской работы; эквивалент можно выполнить в памяти.
