# Десять дел после полуночи

Десять оригинальных детективных noir-кампаний на русском языке для **3–8 игроков
плюс ведущий**. В каждой восемь подготовленных сессий, восемь взрослых героев и
самостоятельное преступление с фиксированной разгадкой. Четыре истории — 18+,
шесть — 21+: взрослость выражается в ответственности и моральной цене решений.

Начните с [локального каталога](index.html). Книги ведущего и исходники содержат
спойлеры; игрокам передавайте только отдельный `players.html` и уже открытые раздатки.

## Проведение

1. Выберите историю и прочитайте её досье ведущего: хронологию, подозреваемых и три
   независимых пути доказательства. Виновник не меняется под версию игроков.
2. Согласуйте темы, паузы и способ делить внимание. В каждой книге описан каждый
   состав 3, 4, 5, 6, 7 и 8; первые три героя образуют самостоятельную команду.
3. Откройте первый вечер. В нём есть чтение вслух, три сцены, развилки, проверки,
   обход неудач, условия выдачи раздаток и последствия решений.
4. Не выдавайте все материалы заранее. Отличайте наблюдение, свидетельство и вывод;
   ошибочное обвинение можно исправить, но оно имеет последствия.

Для 6–8 игроков действуйте парами, ограничивайте отдельную сцену несколькими минутами
и возвращайтесь к общему обсуждению. Отсутствие дополнительного героя не блокирует улику.
Насилие необязательно; любой из трёх подготовленных конфликтов имеет мирный выход.

## Импорт в Living Tabletop World

`package.json` рассчитан на четырёх игроков. Для другого числа используйте
`variants/3-players.json` … `variants/8-players.json`. Импортируйте выбранный файл
в личный черновик Мастерской, проверьте предпросмотр и подтвердите запуск штатным
действием ведущего. Реальные пользователи и приглашения этим пакетом не назначаются.
Для произвольного сочетания героев измените черновик и повторите проверку.

Листы используют поддерживаемые профили третьего уровня как игровые абстракции.
В этой подборке заклинания и ячейки отсутствуют; основной бой — условный ближний
профиль посоха. Огнестрельное оружие, судебные процедуры и медицина не получают
новых автоматических механик. Истории не требуют магии, боя или повышения уровня.
Будущие сцены и исходы — подготовка ведущего, а не уже произошедшая история.

## Состав и воспроизведение

Авторский материал находится в `source/`; `case.json` — закрытая логика дела.
HTML-книги, карты, пакеты и варианты создаются из этих источников. Тактические карты
являются схемами, не оригинальными растровыми иллюстрациями.

```sh
node --conditions=@ltw/source scripts/noir-campaigns/build.ts
node --conditions=@ltw/source scripts/noir-campaigns/render.ts
node --conditions=@ltw/source scripts/noir-campaigns/inventory.ts
pnpm exec vitest run --project unit scripts/noir-campaigns
```

Сборка и рендер принимают slug для точечного запуска. Полный рендер обновляет каталог.
`verification.json` хранит оценки изолированного компилятора и хеши всех вариантов.

Каждую кампанию пишет отдельный агент с запрошенной конфигурацией `gpt-6-astra`,
усилие `max`. Это не провайдерская генерация внутри приложения. Фактически выполненные
проверки приведены в [отчёте](../../reports/NOIR_TEN_2026-11-08.md).
Живой плейтест с людьми не проводился: темп и баланс требуют проверки за столом.
