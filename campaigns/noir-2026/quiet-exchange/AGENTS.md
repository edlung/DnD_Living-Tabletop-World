# «Тихая коммутаторная»

Область автора: только README.md, этот файл и десять JSON в source/.
Контракт: scripts/noir-campaigns/CONTENT_CONTRACT.md; разрешение:
work-orders/NOIR_TEN_2026-11-08.md. Читайте JSON адресно по ключу.

Все источники приватны для ведущего; truth, case, секреты и границы знаний NPC
не попадают в открытые материалы. Раздатки выдаются по unlock, не целиком при старте.
Не редактировать пакеты, HTML, карты, варианты и общие файлы вручную.

Фиксированная виновница — Таисия Коршун. Никакого прослушивания, подмены голоса,
записей, сверхъестественного сигнала или обязательной исповеди. Три независимых
доказательственных пути нельзя сводить к одному документу или свидетелю.
Первичное доверие Романа предшествует кругу взаимных уступок.

Финал — согласованные живые разговоры и отдельные решения по трём доставкам.
Отказ влияет лишь на конкретную доставку при подтверждённом исполнении;
не уничтожает неизвестные копии и не гарантирует будущего молчания виновницы.
Все персонажи 21+, восемь листов уровня 3, магия отсутствует. Сохранять
играбельность для каждого состава 3–8 и возможность отказа от личного раскрытия.

После изменения: loadSource + verifySource для quiet-exchange, проверка русских
названий в прозе, ссылок, возрастов, минут и независимости маршрутов. Общий
prose-audit пишет отчёт вне этой области; автор запускает ту же проверку без
записи общего отчёта, интегратор сохраняет отчёт коллекции.
