# Сад украденной зимы

Авторский источник кампании для смешанной группы подростков и взрослых, 14+.
Читайте README и нужные поля одного файла source. Здесь есть секреты ведущего;
не раздавайте каталог игрокам. Публичные карточки и книги строит общий адаптер.

Ключевой сюжет: необычная эпидемия после зимних плодов, исследовательские вылазки,
разные способы лечения и осознанный выбор каждого пациента. Не заменять это
восстановлением сезонов, охотой на чудовище или переездом поселения.

Все болезни, вещества и лечебные действия вымышлены и магические. Не добавлять
реальные медицинские советы, натуралистические изменения тела, вред детям,
принудительную жертву или потерю права пациента отказаться. Герои заболевают
только по предварительному согласию игрока; сюжет работает без этого.

Правьте только исходные JSON; будущие события — возможности, не факты мира.
Не редактируйте производные package.json, variants или HTML вручную. Структуру
проверяет scripts/dark-fantasy/editorial.ts; новые ключи сверяйте с контрактом.
