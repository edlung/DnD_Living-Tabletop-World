# Десять историй по ту сторону света

Десять самостоятельных дарк-фэнтези кампаний на русском языке: **3–7 игроков плюс
ведущий**, восемь подготовленных встреч в каждой. Первые четыре предназначены для
совместной игры подростков 14+ и взрослых; остальные шесть — 18+.

Откройте [каталог](index.html), выберите историю и начните с первой встречи в книге
ведущего. HTML-книги работают локально, без сервера.

Возрастная пометка описывает содержание. Подробные темы, границы и процедуры смешанного
стола находятся в каждой книге. Возраст игрока не назначает ему героя, профессию или
право решающего голоса. Ведущий не входит в число 3–7 игроков.

## Что входит

- 80 встреч с подготовленными сценами, решениями, последствиями и эпилогами.
- 70 героев 3-го уровня, NPC с ограниченным знанием, улики и отдельные раздатки.
- 50 нативных вариантов состава, необязательные столкновения и тактические SVG-схемы.
- Книги ведущего, отдельные страницы игроков и инструкции по масштабу группы.

Первые три героя каждой кампании образуют рабочую основу. Варианты используют первые
N героев в порядке карточек. Герои 4–7 добавляют возможности, а не обязательные ключи
к сюжету. Для произвольной замены состава отредактируйте черновик и повторите проверку.

## Импорт

1. В мастерской откройте свой черновик и импортируйте `package.json` выбранной кампании
   для **4 игроков** либо `variants/3-players.json` … `variants/7-players.json`.
2. Проверьте героев, первую сцену и встречи в предпросмотре; активацию подтверждает ведущий.
3. Выдайте игрокам `players.html`. Раздатки из `handouts/` передавайте по условиям сцен.
4. Приглашения и управление героями выдаются обычными средствами приложения.

Полная папка содержит тайны ведущего. Для игроков предназначены отдельная страница и
уже выданные раздатки; локальная структура папок не создаёт разграничения доступа.
Страница игроков и отдельные HTML-раздатки содержат оформление внутри файла и пригодны
для передачи по одному. Книгам ведущего нужна общая таблица стилей `book.css`.
Сюжетные условия, превращения и последствия ведёт DM. Подготовленные ситуации не
означают, что будущие события уже произошли.

## Проверки и воспроизведение

```sh
node --conditions=@ltw/source scripts/dark-fantasy/build.ts
node --conditions=@ltw/source scripts/dark-fantasy/render.ts
pnpm exec vitest run --project unit scripts/dark-fantasy
node scripts/dark-fantasy/originality.ts
```

Первые две команды принимают slug для точечной сборки. `verification.json` каждой
кампании содержит результаты компиляции и SHA-256 пакетов. `source/` — авторские
исходники; пакеты и HTML пересоздаются сборщиком.

Каждая история поручена отдельному агенту с конфигурацией **GPT-6 Astra / max** по
прямому запросу владельца. Это авторский материал текущей работы, а не запись о запуске
генератора внутри приложения. Сюжетные отличия описаны в [матрице](DESIGN_MATRIX.md),
сопоставление с доступными соседними кампаниями — в итоговом отчёте.

Растровые иллюстрации не создавались. Живое прохождение, длительность и баланс ещё
не проверены группой. Итог проверок и ограничения:
[отчёт](../../reports/DARK_FANTASY_TEN_2026-11-08.md).
