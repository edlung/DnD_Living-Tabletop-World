# Вдовы соляного моря

Кампания переработана по `campaigns/distinctness/salt-widows-brief.md` (14 ноября 2026) и формату
`scripts/dark-fantasy/CONTENT_CONTRACT.md` с полем `world.engine`.

Читайте `README.md`, затем нужные ключи в `source/` по полю. Четыре файла сессий содержат по два
вечера. Не загружайте целиком производные пакеты, книги и `assets/`.

Секреты ведущего — `truth`, закрытые поля NPC, условия выдачи раздаток, повторный промысел, три
рассказа и все сессии; не копировать их на страницы игроков. Картинки показываются игрокам не
раньше `revealFromEvening` в `assets/manifest.json`.

Числа противников и блоки SRD в `encounters.json` подобраны прогоном движка под готовых героев
(стол от трёх игроков); меняйте их только вместе с повторным прогоном. Полное правило финального боя
— в `dmNote` вечера 8, сцены и встреча ссылаются на него. Текст написан Sonnet 5.5 через API проекта
по скелету Opus 5.5; повторный платный вызов — только по решению владельца
(`scripts/campaign-shared/AGENTS.md`). Картинки — генерация изображений OpenAI; оригиналы и промпты в
`~/Documents/living-tabletop-world-art/salt-widows-2026-11-14/`. Пакеты и HTML не правьте вручную:
редактируется `source/`.
