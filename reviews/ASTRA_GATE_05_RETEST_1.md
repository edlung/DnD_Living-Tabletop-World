## New blocking finding

### [G05-H02] Chronicle permits undo of a cited examination that wrote no facts

- **Severity:** High
- **Invariants:** **11 — EVERY CANONICAL MUTATION IS AUDITABLE** and **12 — WORLD HISTORY IS RECONSTRUCTABLE** for supported temporal domains; ADR 0006 §8 dependency-preserving undo and ADR 0024 §4–5 require a chapter to protect what it tells and retain resolvable sources.
- **Category:** Events / Rollback / Timeline / Observability
- **Preconditions:** Seeded Ravenford, normal player and DM tokens. A valid `inspect` may reveal nothing, including when the same clue was already found.
- **Reproduction:**
  1. As Elowen, enter `old-trade-road`, then `abandoned-caravan-site`.
  2. Submit `ExamineEntity { characterId: "elowen-starwhisper", entityId: "strange-symbol", method: "inspect" }` twice. Both succeed. The second returns `roll: null, discovered: []`; its accepted command is `http:player-elowen:g05-r1-history-4` in the recipe.
  3. As DM, POST `/campaigns/ravenford/chronicle` with a title, `perspective: "DM"` and `from: 0`. The accepted version 3 chapter `chronicle.00000000-00a2-4000-8000-000000000001` contains entry `e8`, **“Elowen Starwhisper examined Strange Symbol.”**, citing the second examination.
  4. Submit `UndoCommand` targeting the second examination while the chapter stands.
  5. Read the DM Chronicle, reload a fresh engine/application from PostgreSQL, and run `redecideEffective` on the command log.
- **Expected:** Refuse the source undo as `UNDO_UNSAFE`, listing the standing chapter. After explicitly undoing the chapter, permit the examination undo. A cited occurrence requires protection even when it discovered or changed nothing.
- **Actual:** Source undo returns **HTTP 200 / accepted**. The stored chapter and prose remain unchanged, but `e8.sources` changes from the examination event to **`[]`**. Re-decision reports the standing `GenerateChronicle` as **`no longer accepted: INVALID_CHRONICLE`**. The same chapter and divergence survive restart. Ordinary replay equality and structural integrity still pass.
- **Evidence:** [Executable recipe](evidence/gate-05/retest-1/SOURCE_OCCURRENCE_PROBES.md), [exact results](evidence/gate-05/retest-1/source-occurrence-results.json), `cases[0]`. The original source is event `00000000-0000-4000-8000-000000000080`, sequence **110**; the chapter is sequence **111**; the accepted undo is sequence **112**. Saved evidence includes the source events, recorded chapter, entry before/after, undo response and oracle result.
- **Independent variant:** `cases[1]` creates an ordinary item without clues and inspects it once. Its chapter entry `e7` loses its source in the same way; no repeated action is required. Each variant uses its own database, so command/chapter identifiers may repeat across cases.
- **Controls:** Both histories re-decide before the source undo. Undo of a cited placement that writes a fact is correctly refused and names the chapter. Player/outsider DM-chapter access remains denied. Undoing the chapter after the faulty source undo restores re-decision equality in both cases.
- **Cause:** [salience.ts](../packages/domain/src/chronicle/salience.ts), lines 120–127, tells every `EvidenceExamined`; line 172 derives its dependencies only from `footprintOf(event).writes`. For a no-roll, no-discovery examination, [facts.ts](../packages/domain/src/kernel/facts.ts), lines 167–170, yields no writes. The added [entry premises](../packages/domain/src/chronicle/entries.ts), lines 67–77, protect names/knowledge/membership but not the existence of the cited occurrence. The undo dependency comparison therefore cannot see that this chapter consumes that command's event. Source resolution correctly excludes the undone event, exposing the orphan entry.
- **Impact:** An ordinary permitted undo leaves a persisted authoritative Chronicle entry telling an occurrence removed from effective history, without a valid source. This is a reproducible dependency/provenance failure, independent of generated prose quality. It is recoverable by undoing the chapter; stored event rows are not corrupted.
- **Remediation direction:** Protect each selected source occurrence/command independently of its state writes. Preserve safe undo of uncited examinations that changed nothing and explicit newest-first recovery of cited ones. Cover the general source boundary, rather than suppressing empty inspections or adding only profile reads. Preserve already-written version 3 chapters under the established earlier-writer contract; capture a genuine current-writer history before any dependency-version change. Do not rewrite stored chapters.
- **Regression required:** **Yes — `chronicle_protects_cited_occurrences_without_fact_writes`**. Include repeated inspection and first inspection without clues, an uncited undo control, refusal naming the chapter, no partial mutation, source resolution, PostgreSQL restart, chapter-first recovery, replay/integrity and re-decision. Add genuine earlier-writer compatibility if the event contract changes.
