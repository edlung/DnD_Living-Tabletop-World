```sh

pnpm exec vitest run --project unit scripts/dark-fantasy
node node_modules/typescript/bin/tsc -p scripts/dark-fantasy/tsconfig.json --pretty false
node node_modules/eslint/bin/eslint.js scripts/dark-fantasy --max-warnings=0
node scripts/context-budget/cli.ts scripts/dark-fantasy
node scripts/dark-fantasy/originality.ts
node scripts/dark-fantasy/layout-audit.ts /Users/oleksandr/.agents/skills/ui-layout-audit/audit.mjs
```

Последняя команда использует установленный Chromium и локальный модуль навыка.

HTTP в проверке блокируется. Пересчёт originality создаёт новый временной срез соседних
источников; он закономерно может отличаться от зафиксированного доказательства.

Авторы проверили отказ NPC, потерю свидетельства, отсутствие дополнительных героев,
ранний успех/уход и частичный итог. Во время сборки исправлены две повторяющиеся
сюжетные цепочки, stale-раздатки/карты, расхождение terrain и позиций, будущий выбор
в тексте ранней улики и чужие секреты в отрицательных формулировках знания NPC.
Все связанные пакеты и книги пересобраны. Контрольные суммы авторских и доставляемых
исходников различены в `authors.json`.
