# Repository-level Tests

Cross-cutting tests that do not belong to one package. Package behavior is tested next to its source (`src/**/*.test.ts`).

- `architecture/` — workspace boundary enforcement (`workspace-boundaries.json`, `docs/adr/0004-module-boundaries.md`).
- `setup/no-network.ts` — every Vitest project's setup file (`vitest.config.ts`): the global `fetch` is a trap, and a test that calls it fails (ADR 0032, checkpoint C). Inject a fake transport instead; `architecture/no-network*.test.ts` prove the trap is active in both projects by its registry symbol, without importing the setup file (so they fail if the configuration stops installing it).
- `i18n/` — dictionary coverage (`docs/adr/0031-play-language.md`): every English client string and every authoring sentence has a Russian entry with the same placeholders. They read sources, so they live here, not in a package.
- `ui-kit/` — the GPT-made UI kit's provenance (ADR 0034): every shipped picture has a manifest entry from the OpenAI image model, every entry has its file, and the client's URL maps name exactly the files; `parchment-contrast.test.ts` measures the GPT pages under the Chronicle's text areas (after the `--page-floor` veil) and holds every page ink to 4.5:1 there; `chronicle-art-contrast.test.ts` holds a chapter's title on the red ribbon of its tab (at the lightest shade a tab takes, every pixel its words can lie on) and the book's title on the shaded top of the candle-lit desk to 4.5:1.
- `evidence/` — screenshot tours (`pnpm evidence:screens`, `playwright.evidence.config.ts`); not run by `pnpm test:e2e` or CI. See `e2e/AGENTS.md`.
- `deploy/` — browser journeys against a running deployment (Stage 350, ADR 0037 "Full product"): `playwright.deploy.config.ts`, run only by `deploy/verify/browser-journey.sh` (and `deploy/verify/ci.sh`), never by `pnpm test:e2e`, `pnpm validate` or the main CI job. Chromium reaches Caddy at `PUBLIC_ORIGIN` and trusts the deployment's local CA for the run by its intermediate's SPKI; the operator's link comes from the server container. Real links and cookies: no trace, screenshot or video, assertions about a token are yes/no, and the wrapper removes the output directory. The journey frees a seat an earlier run left taken and walks Elowen back to the market square when a run left her elsewhere.
- `e2e/` — Stage 200 real browser/API journeys. Start with `e2e/AGENTS.md`; Playwright uses dedicated in-memory HTTP and Vite servers.
- Later cross-package suites remain split by behavior or user scenario, with shared fixtures in small support modules.
