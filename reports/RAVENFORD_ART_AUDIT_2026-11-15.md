Пайплайн рабочий и документированный: Codex CLI на подписке ChatGPT → `scripts/curated-set/cli.ts`
(мир) или `scripts/ui-kit/cli.ts` (интерфейс) → манифест с промптом и SHA-256 → импорт как
одобренные ДМ ассеты. В игре новые картинки идут через OpenRouter с фиксированным
`STYLE_PROMPT` (`apps/server/src/images/style.ts`) и двумя эталонами Ravenford на группу
(`style-references.ts`: Мира+Орин, площадь+«Золотой олень», колесо+гоблинский нож).

Визуально Ravenford-набор цельный: янтарный свет против холодной синевы, золото, дымка; портреты 1:1,
места 3:2, фигурка — расписная миниатюра на круглой каменной подставке.

## 2. Дыры в том, что уже отгружено

**Враги без картинок в готовых боях** (импорт привязан к ID сущности):

- Ravenford, «Засада на Старой дороге»: 11 врагов, картинка есть у 4. Ещё 3 налётчика и 1 шаман —
  арт есть, просто их ID нет в манифесте. **Серый ворг (×2) и гоблин-вожак — арта нет вообще.**
- Hollowmere: 2 из 4 Ashen Acolyte не привязаны (арт есть). **Нет арта:** Swarm of Rats, Giant Frog
  (×2), Reed Cloak Lookout (×2).
- Готовые герои: у Бранна, Тамсин, Марен (Ravenford) и у 4 героев Hollowmere нет ни портрета, ни
  фигурки. ADR 0058 фиксирует причину: ID героя новый в каждой копии, импорт по ID его не находит.
  Библиотека кампаний это уже решила привязкой по ключу сущности, у Ravenford и Hollowmere такой
  привязки нет.

**Боевые карты:** у Hollowmere 7 подготовленных боёв и 0 карт (бой идёт на общей текстуре земли);
у Ravenford одна. У кампаний библиотеки карты есть для каждого боя.

**Объекты истории Hollowmere без картинок:** Колокол Холлоумира, Утонувший алтарь, Затонувший
колокол, Огни топи, Фонарь откровения, Булава святого Одрана, Просмолённая книга, груз Агны;
эмблемы фракций Reed Cloaks и Ashen Circle.

Оговорка: дыры найдены сверкой манифестов с сидами и `encounters.json`. В запущенном приложении
я их не проверял.

## 3. Расхождения стиля

1. **Hollowmere рисовали по концептам, а не по эталонам Ravenford.** Ссылки в его манифесте — только
   `owner-concepts/*`. Итог: гоблин-налётчик Hollowmere — другой дизайн (в овчине), чем гоблин
   Ravenford (в коже со щитом), хотя мир один.
2. **Свет.** Базовые места Ravenford — золотой час, вечер или солнечное утро в тёплой гамме с
   глубокими тенями, плюс ночные и дождевые варианты. Часть мест Hollowmere — плоский серый или
   пастельный день почти без теней (сама деревня, Mill Road, Willow Ford; замер — в арт-библии, §11).
   На одной карте региона это читается как два разных художника. (Исправлено после замера: в первой
   версии было «Ravenford почти весь ночной», но база Рыночной площади утренняя.)
3. **Нет вариантов** погоды и времени суток у Hollowmere, хотя глифы погоды (рассвет, сумерки, туман,
   снег, шторм) и логика вариантов в `style.ts` уже есть.
4. Мелочь: иконки школ «очарование» (розовое сердце) и «вызов» (фиолетовый) выходят за палитру
   (янтарь, синий, бирюза, угольно-красный).
5. **Нет единого стиль-гайда.** Стиль раскидан по `style.ts`, промптам в манифестах и ADR 0034.
   У кампаний библиотеки свои стили на кампанию (`style.txt`; например, у Marrow Crown монохромный
   красно-костяной, портреты 3:4, фигурки без подставки). Для отдельных миров это нормально, но эти
   инструменты (`scripts/campaign-shared/`) не дают стиль Ravenford.

## 4. Что нужно для масштабирования вселенной

### Сначала: правила стиля (без них каждое новое приключение будет дрейфовать)

- **Арт-библия Ravenford** (`docs/design/ravenford-art-bible.md`): палитра и свет, кадр для каждого
  назначения (портрет 1:1, место 3:2, объект 1:1, фигурка на подставке, боевая карта сверху 4:3),
  правила вариантов, запреты (текст, руны-буквы, улики), эталонный лист из 8–12 картинок.
- **Эталоны в каждом запросе:** картинки Ravenford по группе, как уже делает живой генератор, а не
  только концепты.
- **Модельные листы повторяющихся лиц и рас:** Эловен, Мира, Орин, Торн; гоблины, ворги, нежить.
  Решение владельца: какой гоблин канон.
- **Генератор приключения в репозитории.** `generate.py` Hollowmere лежит только в папке оригиналов.
  Нужен общий скрипт для приключений вселенной (по образцу `campaign-shared`): пишет промпты из сида,
  подставляет эталоны Ravenford, привязывает картинки по ключу.
- **Тест полноты:** у каждого врага подготовленного боя есть фигурка, у каждого места боя — карта,
  у каждого готового героя — портрет. Он бы поймал все дыры раздела 2.

### Закрыть дыры (P0) — около 35 картинок

| Боевые карты 7 боёв Hollowmere по их сеткам                                              | 7                   |

| Ворг/вожак: «ранен»                                                                      | 2                   |

### Выровнять Hollowmere (P1) — около 30 картинок

- Ночь, туман и дождь для 5–6 ключевых мест Hollowmere (≈15).
- 8 объектов истории и 2 эмблемы фракций (≈10).
- По решению владельца: перерисовать 3–4 дневных места в ночной гамме Ravenford и согласовать
  гоблина (≈5).

### Рост вселенной (P2)

- **Сам Ravenford:** интерьеры (зал «Золотого оленя», гильдия, лавка Орина, караулка ворот),
  кварталы (порт/доки, храм, трущобы), горожане 6–10 человек, снег/зима для городских сцен;
  карта Ravenford и окрестностей шире топей.
- **Каждое новое приключение уровня Hollowmere:** ~13 мест (+варианты), ~6 NPC, ~10 видов врагов ×2,
  ~7 боевых карт, ~10 объектов, карта региона — **≈70–80 картинок**, при ~2 мин на картинку через
  Codex ≈ 3 часа генерации плюс отбор.
- **Каталог SRD:** монстров 330, а картинок только 14 (по типу) → бестиарий 40–60 частых монстров
  CR 0–5. Заклинаний 339, картинок 8 (+8 школ) → 30–40 частых заклинаний 0–3 круга. Магических
  предметов 258 → 20–30 частых. Классы (12) и виды (9) без арта → заглушки портрета для конструктора
  героя.

Всё новое — через модель изображений OpenAI (правило владельца), с оригиналами вне репозитория и
пересборкой через манифест. Изменённые байты уже отгруженного арта — только с одобрения владельца.
