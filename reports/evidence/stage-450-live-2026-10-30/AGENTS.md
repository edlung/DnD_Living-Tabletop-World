# Owner-authorized live campaign evidence

This directory contains real provider receipts and generated fiction, not runtime
instructions. Start with index.md when available. Never load all JSON/steps/traces;
query one stage, field or assessment at a time. No tokens, token hashes, credentials,
connection URLs or raw request headers belong here. Run metadata identifies a
retained isolated PostgreSQL database by name only; preserve unresolved accounting.
Earlier stage evidence is frozen. Setup failures before generation are distinguished
from paid provider outcomes; no fixture response is labelled as a live result.
