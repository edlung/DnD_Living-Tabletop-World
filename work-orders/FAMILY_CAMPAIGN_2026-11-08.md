# Маяк Между Ветрами — family campaign

Owner authority: the active goal of 2026-11-08 requests a complete, illustrated campaign for
this project and fixes to problems encountered. The owner selected one adult DM, three players
(8, 14 and an adult), and wonder, mystery, humour and an affecting ending.

## Authorized scope

- An original Russian campaign for twelve evenings, with a complete beginning, branching middle,
  climax and epilogues; three active heroes and a fourth optional choice. No age/gender role locks.
- A practical DM book, player-safe handouts, supported character sheets, locations, NPC knowledge,
  clues, optional encounters, props, items and outcomes. Essential clues never depend on one roll.
- Real generated raster art saved in the repository, an asset/provenance manifest and usable
  presentation materials; campaign art stays distinct from the product's existing Ravenford assets.
- A native version-1 CampaignPackage, checked through the existing isolated compiler and World
  Engine; local preview/play verification and a concrete import/start workflow using existing
  authority and confirmation boundaries. Any narrowly necessary integration fix gets regression
  coverage. No fabricated provider jobs, human play acceptance or pre-played future events.
- Relevant checks, an adversarial knowledge/agency/content pass and a reproducible handoff.

This is a content delivery work order under the current goal, not permission to begin another
numbered product stage. The session writes and checks its own work. Existing review history stays.

## Boundaries

No production deployment/publication, credential changes, production dependencies, paid project
provider calls, external messages or live campaign activation are authorized. The user explicitly
requested art, so the built-in imagegen tool may create the requested assets without project API
credentials. Generated files record their actual source, never a fictitious runtime image job.
Initial state contains only the opening; later scenes remain plans until the DM acts through normal
commands. Knowledge, item and quest rules remain the existing project's contracts.

## Deliverables / checks

Content and art: `campaigns/lighthouse/`. Native loader/validation and launch support: scoped
server modules and scripts as needed, referenced from that folder's README. Validate all packages,
references, three-player encounters, spoiler boundaries, art hashes and file sizes; render and
inspect presentation materials. Run repository validation when implementation is ready and record
environment blockers honestly. Final report includes file identity, checks, limitations and the
owner's remaining local play/activation decision.
