# Campaign library (generated)

Written by `scripts/campaign-library/build.ts` from `campaigns/`; never edit by hand. Each folder
holds one campaign the workshop offers: `library.json` (its variants, their package digests and
its pictures bound by package key, read from the campaign's own `assets/`), `packages/` and
`book.json` (the DM's book, ADR 0074 §2: the campaign's chapters and scenes as its source wrote
them; the DM's text, never a player's). Read `library.json` by key.
