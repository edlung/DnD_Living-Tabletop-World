# Сквозные боевые прогоны

Запускайте из корня проекта. `pnpm campaigns:endurance --out /tmp/ltw-endurance` проверяет все книги. После параметров можно указать отдельные кампании. `--seeds 32 --start 1000` воспроизводит независимую серию. `--itineraries scripts/campaign-endurance/prior-routes.json` воспроизводит исходные маршруты двух исправленных книг.

- В `itineraries.json` лежат порядок боёв и основания для отдыха. Ключи сверяются с каждым игровым пакетом. `choices.mjs` задаёт решения, которые приводят к разным финальным раскладам.
- `run.mjs` запускает серии. `journey.mjs` проводит один изолированный стол от первой сцены до конца. Переход меняет место и расстановку. `resources.mjs` применяет правила лечения, имущества, уровней и отдыха к сохранившимся листам. Расходники из раздаток, для которых нет числового каталожного предмета, описаны в `supplies.mjs`.
- `special.py` подключает авторские модели шести финалов к дошедшим персонажам. Хиты, доступные заклинания и применения классовых умений проверяются для каждого места. Разные модули с именем sim запускаются в разных процессах с фиксированным PYTHONHASHSEED.
- `summary.py` сверяет вход и выход соседних сцен, составы, уникальность семян и исходы. `publish.py` собирает две серии, исходные серии и папку результата из пяти позиционных путей. В отчётах и архивах есть тайны ведущего.
