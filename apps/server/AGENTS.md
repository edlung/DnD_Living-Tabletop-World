# Server (`@ltw/server`)

Composition root of the modular monolith and the only workspace package allowed to perform I/O (`docs/adr/0004-module-boundaries.md`).

| Area                 | Entry                                                                                                                                                         | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Process start        | `src/main.ts`                                                                                                                                                 | Wires config, logging, HTTP, and the asset worker loop. No domain logic here.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Config               | `src/platform/config/config.ts`                                                                                                                               | Add variables to the zod schema; never echo values in errors.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Logging              | `src/platform/logging/logger.ts`                                                                                                                              | Use child loggers; bind request/actor/scope fields.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Database migrations  | `src/platform/db/`, `migrations/`                                                                                                                             | Read `migrations/AGENTS.md` before adding SQL.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| HTTP app             | `src/http/app.ts`, `src/http/routes/`                                                                                                                         | Fastify (ADR 0009). Check order in `request-context.ts`; fixed error bodies in `errors.ts`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Authentication       | `src/http/auth.ts`                                                                                                                                            | Dev persona tokens only outside production; actors never come from request data.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Memory routes        | `src/http/routes/memory-routes.ts`                                                                                                                            | Scoped recall (`/memories`), single memory, member-only `/sessions` (ADR 0010).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| World Engine runtime | `src/world-engine/runtime.ts`, `src/world-engine/postgres-event-store.ts`                                                                                     | PostgreSQL EventStore; the only canonical write path. Skill checks use `@ltw/rules` with crypto dice; combat uses `@ltw/combat` with crypto entropy recorded per command (ADR 0015).                                                                                                                                                                                                                                                                                                                                                                                                      |
| Context route        | `src/http/routes/context-routes.ts`                                                                                                                           | Entity context for an acting character (ADR 0012). `ranking=ai` asks the relevance ranker within `LTW_AI_RELEVANCE_BUDGET_MS` (ADR 0021); any failure answers the deterministic context (`context-ranking.test.ts`).                                                                                                                                                                                                                                                                                                                                                                      |
| Encounter route      | `src/http/routes/encounter-routes.ts`                                                                                                                         | Perspective-scoped encounter view from `@ltw/combat` (ADR 0015 §6), including the open reaction window (ADR 0016 §4); `encounter: null` outside the fight. `GET …/encounter/suggestion`: the DM's monster suggestion (ADR 0020 §5).                                                                                                                                                                                                                                                                                                                                                       |
| NPC dialogue         | `src/http/routes/npc-routes.ts`                                                                                                                               | ADR 0020 §1, §3. Talk check, then the intent's command through the World Engine, then a traced reply from the NPC's minimal context. Logs never carry the player's words or the reply. Tests: `npc-dialogue.test.ts`, `npc-isolation.test.ts` (Gate 04 markers).                                                                                                                                                                                                                                                                                                                          |
| Player commands      | `src/http/routes/command-routes.ts`                                                                                                                           | Players submit their character's investigation commands. Results pass through `forPlayer`: an `outcome`, no event list, no details, no `expectedVersion` (ADR 0013, ADR 0014 §4).                                                                                                                                                                                                                                                                                                                                                                                                         |
| AI gateway           | `src/ai/gateway.ts`, `src/ai/anthropic-provider.ts`, `src/ai/postgres-trace-store.ts`, `src/http/routes/ai-routes.ts`                                         | ADR 0017. DM-only intent proposals and traces. The gateway gets no World Engine and no route submits a proposal. The API key lives in a `Secret` (config) and is never logged or traced; tests inject `fetch` and never reach the network.                                                                                                                                                                                                                                                                                                                                                |
| Authoring            | `src/authoring/service.ts`, `src/authoring/proposal-store.ts`, `src/authoring/postgres-proposal-store.ts`, `src/http/routes/authoring-routes.ts`              | ADR 0018. DM-only proposals, revisions (the DM's own, or a preview option applied on request, ADR 0019 §1), previews, confirmed commits (`authoring.<proposalId>`), and undo. Legality and consent are the World Engine's; the service binds a commit to the latest revision. Edits, commits, and undos of one proposal take turns (`ProposalStore.exclusive`: a PostgreSQL advisory lock, on its own pool from `main.ts`), and an identical commit retry is `duplicate` (Gate 04 remediation; `proposal-races.integration.test.ts`). The generic command route refuses `ApplyAuthoring`. |
| Assets               | `src/assets/worker.ts`, `src/assets/worker-loop.ts`, `src/assets/content-store.ts`, `src/assets/postgres-content-store.ts`, `src/http/routes/asset-routes.ts` | ADR 0022. The asset worker (system actor `asset-worker`, deterministic command IDs) runs queued requests through the image generator (local placeholder only) every `LTW_ASSET_WORKER_INTERVAL_MS`; bytes go to the append-only content store (migration 0004). Routes: the DM lineage, a perspective's entity assets, and content by hash with a CSP; anything not visible is the same 404 as nothing. Requests, cancels, retractions, and approvals are commands. Tests: `worker.test.ts`, `asset-routes.test.ts` (Gate 04 hooded watcher), `assets.integration.test.ts`.               |
| Ravenford seeding    | `src/world-engine/seed-ravenford-cli.ts`                                                                                                                      | Idempotent; `pnpm seed:ravenford` after `pnpm build` and `pnpm db:migrate`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |

- Later domain modules go under `src/<feature>/`, each cohesive and imported directly; keep orchestration thin.
- Canonical mutation stays behind the World Engine boundary (`ARCHITECTURE_INVARIANTS.md` #1–2). Platform code never decides domain legality.
- `*.integration.test.ts` needs PostgreSQL (`pnpm db:up`); everything else is a unit test. Integration tests create a throwaway database each via `src/testing/throwaway-database.ts`.
- Canonical kernel state is never served over HTTP. Player-facing reads go through the knowledge perspectives (`resolvePerspective` and the queries in `@ltw/domain`); never add a route that returns canonical objects.
- HTTP tests use `src/testing/ravenford-app.ts` (seeded in-memory engine, real persona tokens, `testAiGateway` with the local provider and in-memory traces, `testAuthoring` with in-memory proposals, `testAssets` with in-memory contents, and `post`) and the shared spec `fixtures/ravenford/knowledge-boundary.json`.
