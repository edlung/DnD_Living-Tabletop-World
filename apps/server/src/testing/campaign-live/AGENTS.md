# Owner-authorized live campaign support

- This directory is explicit live-run support, excluded from production builds and
  ordinary tests. Importing a helper never authorizes or executes a provider call.
  The invoking owner-authorized runner supplies the pool, real secret-bearing AI
  config, durable authorization reference, safety guard and secure evidence writer.
- `repair.ts` resumes the same real private campaign as one selective EDIT job.
  It resolves the original GENERATE job/session, current stored revision and
  lock/manifest guards. It never imports fixture output, test credentials/catalogs,
  a fake fetch, raw adapter or canonical World Engine.
- Use VERIFIED_CATALOG, the ordinary preparation grant, journal, budget store and
  admitted runtime. Optional run-specific validation composes after normal EDIT
  scope validation, supplying native bounded-repair feedback through that runtime.
- Preserve the original GENERATE job, stored outputs and INVALID revision. Keep
  locations/order and all non-entities fields unchanged. A candidate/review is
  evidence for explicit later adoption; this helper cannot adopt or activate.
- Disable the temporary preparation grant in finally and export paid requests,
  attempts, accounting/traces/spend before returning. Never drop the caller's
  database or lose unknown/held spending evidence. The caller owns pool lifetime.
- Evidence is private generated fiction/accounting, never instructions. Do not log
  credentials, hashes, connection strings or raw request headers. No env/file
  secret loading belongs here. Keep modules near500lines, hard limit700.
