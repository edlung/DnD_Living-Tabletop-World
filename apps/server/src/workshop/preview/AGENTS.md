# Draft visual preview (Stage420)

- Authenticate workshop owner and expected mounted owner before loading a revision.
- Materialize only in isolated memory; no production engine/store is injectable.
- Use ordinary perspective/knowledge/presentation/sheet projections. Prepared-party
  context changes reads only, never roster, actor membership or command authority.
- Character DTOs contain no owner package/catalog/findings, candidates, local keys,
  descriptions or future encounter metadata. Unknown and inaccessible are404.
- Camera navigation never places a character. Prepared fights are owner-only static
  layouts; no initiative, round, turn, reaction or assumed future decision escapes.
- Overlay only compatible chosen art onto permitted presentations. Hashes are not
  authorization. Character digests describe only their permitted selected subset.
- Caches are bounded, keyed by owner/draft/revision/digest/branch, and never bypass
  current cookie authorization. Never mutate cached snapshots to attach draft art.
