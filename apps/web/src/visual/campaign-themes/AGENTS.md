# Campaign surface materials

Public catalogue of authored titles, ornamental materials, accent colours and Cyrillic type
families. Only the public campaign name or library ID selects a theme. An unmatched name uses the
base appearance. World pictures, portraits and items still come from the viewer's approved
projection. Dice may use the material as an overlay; labels and values remain the server's.
Catalogue and pictures are verified by the campaign-interface checks. Source and usage notes:
work-orders/CAMPAIGN_EDITORIAL_2026-11-22.md.
