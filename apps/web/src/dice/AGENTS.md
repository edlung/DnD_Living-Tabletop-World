# Dice in the client (`src/dice/`, Stage 510)

ADR 0040; work order `work-orders/STAGE_510.md`. Every die shown is the server's: the client reads the
roll feed and animates rolls new to it; it never decides a number.

| File                                                                                                                  | Role                                                                                                                                                                                                                                                                                                                             |
| --------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `table.tsx`                                                                                                           | `useDiceTableState`: the feed and the DM's requests (live re-reads), new rolls once each, writes (roll, ask, cancel); the context the stage, sheet and panels read                                                                                                                                                               |
| `dice-stage.tsx`                                                                                                      | The top-layer popover with the canvas and the plate: queue, lazy engine, sound, landing → log and announcement                                                                                                                                                                                                                   |
| `engine/`                                                                                                             | Lazy chunk: `solids.ts` (polyhedra and numbering, tested), `landing.ts` (top face, one-swap relabel, percentile), `simulate.ts` (cannon-es throw recorded first), `mesh.ts` (chamfered geometry), `labels.ts` (GPT surface + numerals), `engine.ts` (three.js scene and playback), `index.ts` (loads the GPT textures and fonts) |
| `audio.ts`                                                                                                            | Synthesized impacts per bounce; unlocked on the first gesture                                                                                                                                                                                                                                                                    |
| `settings.ts`                                                                                                         | Per-viewer sound, volume, motion (browser storage, safe when unavailable)                                                                                                                                                                                                                                                        |
| `dice-panel.tsx`, `roll-builder.tsx`, `check-forms.tsx`, `requests-log.tsx`, `checks.ts`, `words.ts`, `announcer.tsx` | The Dice sheet, the words, the polite announcement                                                                                                                                                                                                                                                                               |

- Players' dice are obsidian with gold numerals, the DM's (and hidden or monster rolls) ivory.
- The canvas and plate are decorative (`aria-hidden`); `RollAnnouncer` says the roll where the viewer is
  (inside the character dialog while it is open).
- Tests: `engine/*.test.ts`, `audio.test.ts`; journeys `tests/e2e/dice.spec.ts`.
