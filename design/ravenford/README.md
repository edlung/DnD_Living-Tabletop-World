# Ravenford visual production workspace

Initial state: planning inventory only. No graphics have been generated or approved by this package.

Use [the graphics package](../../docs/graphics/README.md) and one authorized [work order](../../work-orders/sol-graphics/README.md).

GFX00 creates visual-brief.md, decisions.md, and a report under reports/. Later jobs create their named sources, previews, and exports. The asset register tracks planned resources and actual handoff files. Query it narrowly instead of opening all outputs.

Folders are created by the job that needs them. Empty placeholder folders and fabricated file links are unnecessary.
