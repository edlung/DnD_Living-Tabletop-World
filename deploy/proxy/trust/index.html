Living Tabletop World

Стол на ноутбуке мастера

Игра идёт на ноутбуке мастера, в этой сети. Чтобы телефон открыл её по защищённой связи, один раз установите сертификат ноутбука.

Проверяем, доверяет ли телефон ноутбуку…

Телефон доверяет ноутбуку: можно играть.

Телефон пока не доверяет ноутбуку: установите сертификат по шагам ниже.

Открыть стол

Скачать сертификат ноутбука

iPhone или iPad

  1. Откройте эту страницу в Safari и нажмите «Скачать сертификат ноутбука», затем «Разрешить».
  2. Настройки → «Профиль загружен» → «Установить» (попросит код-пароль).
  3. Настройки → Основные → Об этом устройстве → Доверие сертификатам → включите «Living Tabletop World local root».
  4. Вернитесь сюда и нажмите «Проверить снова».

Android

  1. Нажмите «Скачать сертификат ноутбука».
  2. Настройки → Безопасность → Другие настройки безопасности → Шифрование и учётные данные → Установить сертификат → Сертификат ЦС → «Всё равно установить» → выберите ltw-local-root.crt. Названия пунктов зависят от производителя: ищите «сертификат ЦС».
  3. Вернитесь сюда и нажмите «Проверить снова».

Компьютер у телевизора

macOS: откройте скачанный файл, в «Связке ключей» дважды щёлкните сертификат → «Доверие» → «Всегда доверять». Windows: откройте файл → «Установить сертификат» → «Доверенные корневые центры сертификации». На ноутбуке мастера это делает команда deploy/local/ltw-local.sh trust-here.

Что значит этот сертификат

Он позволяет устройству доверять игре на ноутбуке мастера. Такой корневой сертификат может подтвердить любой сайт, поэтому ставьте его только с ноутбука своего мастера, дома, и удалите, когда больше не играете у него: на iPhone — Настройки → Основные → VPN и управление устройством → профиль → «Удалить»; на Android — «Учётные данные пользователя».

The table on the DM’s laptop

The game runs on the DM’s laptop, on this network. To open it over a secure connection, install the laptop’s certificate on this phone once.

Checking whether this phone trusts the laptop…

This phone trusts the laptop: you can play.

This phone does not trust the laptop yet: install its certificate with the steps below.

Open the table

Download the laptop’s certificate

iPhone or iPad

  1. Open this page in Safari, tap “Download the laptop’s certificate”, then “Allow”.
  2. Settings → “Profile Downloaded” → “Install” (it asks for the passcode).
  3. Settings → General → About → Certificate Trust Settings → turn on “Living Tabletop World local root”.
  4. Come back here and tap “Check again”.

Android

  1. Tap “Download the laptop’s certificate”.
  2. Settings → Security → More security settings → Encryption and credentials → Install a certificate → CA certificate → “Install anyway” → choose ltw-local-root.crt. Makers name these differently: look for “CA certificate”.
  3. Come back here and tap “Check again”.

A computer by the TV

macOS: open the downloaded file, double-click the certificate in Keychain Access → Trust → “Always Trust”. Windows: open the file → “Install Certificate” → “Trusted Root Certification Authorities”. On the DM’s laptop, deploy/local/ltw-local.sh trust-here does it.

What this certificate means

It lets this device trust the game on the DM’s laptop. A root certificate like this can vouch for any site, so install it only from your own DM’s laptop, at home, and remove it when you no longer play there: on an iPhone, Settings → General → VPN & Device Management → the profile → “Remove Profile”; on Android, “User credentials”.
