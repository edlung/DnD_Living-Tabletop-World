# Сессия N — запись

Копия этого файла на каждую сессию: `reports/evidence/stage-360/session-N.md`.
Без токенов, ссылок-приглашений и личных данных.

## Условия

| Поле                                   | Значение                              |
| -------------------------------------- | ------------------------------------- |
| Дата, время начала и конца             |                                       |
| Ревизия (короткий хеш), где развёрнута |                                       |
| Роли                                   | DM: Участник ?; игрок: Участник ?     |
| Опыт настольных ролевых игр (со слов)  | DM: ; игрок:                          |
| Живой ИИ                               | включён / выключен; потолок на сессию |
| Картинки по просьбе DM                 | включены (потолок) / заглушки         |
| Расходы сессии (`spend.sh`)            |                                       |
| Согласия (`consent-ru.md`)             | текст: да/нет; запись экрана: да/нет  |
| Наблюдатель                            |                                       |
| Отклонения от протокола                |                                       |

таблицы выше в пользу каждого ответа (наблюдения, не толкования).
