# Иллюстрации пробного издания

Это отдельный комплект «Маяка Между Ветрами» для концепта книжной полки. В `manifest.json` у каждой исходной генерации указаны запрос, SHA-256 оригинала и изображения WebP, сделанные из него. Для проверки отдельного объекта ищите его имя в поле `files`.

Портреты, фигурки и изображения сцен привязаны к одним и тем же персонажам. Цвет кожи людей и человекоподобных героев в этом издании светлый по указанию владельца. Для идентификации персонажей также сохраняйте возраст, причёску, одежду и узнаваемые предметы. Прозрачность фигурок и кубиков нужна игровому полю. Карта даёт иллюстрацию местности, а координаты фигур задаёт встреча.
